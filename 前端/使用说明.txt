小红书下载工作台

双击上一级文件夹“打开下载页面.bat”。
工作台：http://127.0.0.1:5557/
接口文档：http://127.0.0.1:5557/api-docs

日常操作
1. 在工作台选择保存位置。
2. 下载笔记：粘贴具体笔记链接或分享文案，多条可一起粘贴。
3. 下载作者作品集：切换“作者作品集”，输入完整作者主页链接，点击获取。
   如打开Edge登录窗口，请在服务器这台电脑扫码；验证或登录状态会显示在工作台。
4. 等待采集结束后，下载全部已采集作品或指定作品。
   “全部”以当前账号可见作品为准；部分结果不代表作者所有历史作品。
5. 在任务列表查看进度，打开作品文件夹。

保存结构：所选文件夹/作者名/作品标题/图片或视频，以及作品说明.txt。
同名冲突会附加作品ID。管理与校验记录保存在程序内部数据库，不在作品中生成JSON。
任务和采集结果会持久保存。重启后未完成下载恢复排队；中断的作者采集保留已有结果。
“清除已结束任务”只清记录，不删除作品文件。
“仅解析”返回资源网址，不下载文件。资源网址可能过期，需要时重新解析。

其他应用调用
接口统一前缀 /api/v1。完整说明与Python客户端在上一级“接口示例”目录。
在本机接口文档点击“显示并填入本机API Key”，再使用Try it out测试。
其他程序必须发送 Authorization: Bearer <API_KEY>。
下载接口返回202表示接收，需要查询任务到done才表示全部成功。
作者采集、作品分页、任务查询/取消/重试、文件下载均有接口。
旧 /api/xhs/detail 代理已停用，避免绕过保存规则。

局域网共享
默认仅在127.0.0.1:5557提供工作台与新接口。
管理员双击“打开局域网共享.bat”后，其他电脑可用服务器局域网IP访问5557接口。
切换时如有活动任务会拒绝重启，请先等待或停止任务。
防火墙按需只允许可信局域网入站5557；原始内部服务5556/5558不受新密钥保护，不应对外开放。
共享脚本不会自动配置防火墙，也不会发布到互联网。
双击“关闭局域网共享.bat”可在无活动任务时切回仅本机监听。
工作台及系统目录操作始终仅允许本机；远程仅提供接口文档和带密钥的API。

在另一台Windows电脑独立安装服务
需要原始程序完整目录与Python3.10+。启动器支持系统Python，无需Codex。
作者采集额外需要Node.js、Microsoft Edge，以及在前端目录执行：
  npm install --no-save playwright
也支持环境变量 XHS_NODE_EXECUTABLE 与 XHS_PLAYWRIGHT_MODULE 指定运行环境路径。
不要复制已有browser-profile、数据库、日志或带Cookie的个人配置给其他人。
