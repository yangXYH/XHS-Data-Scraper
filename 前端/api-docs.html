小红书下载服务

把作品链接提交给服务，查询处理进度，再获取图片或视频。单篇笔记与作者作品集都按「作者名 / 作品标题」整理保存。

01获取管理员提供的 API Key02点击 Authorize 填入密钥03提交任务并轮询结果

接口地址：　鉴权：Authorization: Bearer <API_KEY>

提交成功返回 202，随后查询任务：done 成功、warning 部分成功、failed 失败、cancelled 已停止。资源文件需要使用同一密钥下载。

文件首先保存在服务器管理员选定的目录。其他电脑通过文件接口下载到自己的电脑。作者采集如显示 login 或 attention，需要服务器操作员在 Edge 窗口登录或完成验证；只能取得当前账号可见的作品。

此按钮仅本机管理员可用。密钥重启后有效，请仅提供给可信的调用方；不要将浏览器登录资料一并发送。

远程访问需由管理员启动「打开局域网共享.bat」，使用服务器局域网 IP，并按需允许 Windows 防火墙入站端口 5557。本机默认仅监听 127.0.0.1。请勿直接暴露到公网。

交互文档加载中。也可下载 OpenAPI 规范导入接口工具。
接口不依赖工作台页面令牌。POST 请求使用 JSON；建议提供 Idempotency-Key，避免网络重试重复创建任务。工作台设置与系统文件夹操作仅允许本机使用。
