# 小红书下载服务 · API v1

这套接口可以由 Python、curl、Postman、Apifox 或其他应用调用，不需要打开工作台，也不依赖页面临时令牌。所有下载都进入工作台的同一个队列，保存位置沿用管理员在工作台选择的目录。

## 1. 管理员启动与提供密钥

程序目录：`D:\XHS-Data-Scraper`。

- 本机使用：双击 `打开下载页面.bat`。
- 接口文档：打开 `http://127.0.0.1:5557/api-docs`，点击“显示并填入本机 API Key”。可以直接在文档里展开接口，点击 **Try it out → Execute** 测试。
- 向调用者提供服务地址与 API Key。Key 持久保存在服务器内部数据库中，重启后不变。工作台页面令牌与 API Key 是不同凭证。
- 只允许本机管理员改变保存位置、选择系统目录或打开资源管理器。

## 2. 其他电脑调用

管理员双击 `打开局域网共享.bat`。该脚本会切换本服务为 `0.0.0.0:5557`；如有正在处理的任务会拒绝切换，请先完成或停止任务。脚本显示服务器局域网 IPv4 地址。

调用者使用 `http://服务器局域网IP:5557/api/v1`。`127.0.0.1` 只能访问调用者自己的电脑。

若 Windows 防火墙阻止访问，由管理员按需仅允许可信局域网对 **TCP 5557** 的入站访问。原程序另有 **5556/5558** 内部服务，不受新 API Key 保护，不能向调用者开放；请保持这两个端口被防火墙阻止。共享脚本不自动改变防火墙。HTTP 仅适合可信局域网；公网接入需另行配置 HTTPS、网络访问控制与反向代理。

退出共享：双击 `关闭局域网共享.bat`，会在没有活动任务时切回仅本机监听。普通“打开下载页面”不会中断一个已经运行的共享实例。

远程文档可打开 `http://服务器局域网IP:5557/api-docs`，使用 **Authorize** 手动输入管理员提供的密钥。密钥输入框只填 Key 本身，不填 `Bearer` 前缀。

## 3. 用交付的 Python 客户端下载一篇笔记

需要 Python 3.10+，无需安装第三方包。将 `xhs_client.py` 发给调用者即可，不要发送服务器登录资料或数据库。

在 PowerShell 中：

```powershell
$env:XHS_API_KEY = '管理员提供的密钥'
$env:XHS_BASE_URL = 'http://服务器IP:5557'
python .\xhs_client.py health
python .\xhs_client.py --out 'D:\下载作品' download '完整笔记分享链接'
```

笔记链接需要保留原有 `xsec_token` 等参数。单篇笔记支持完整链接与 `xhslink.com` 短链。作者主页请使用作者采集接口。

```powershell
# 只解析，不保存资源
python .\xhs_client.py parse '完整笔记链接'
# 只下载第1张和第3张
python .\xhs_client.py --index 1 3 --out 'D:\下载作品' download '完整笔记链接'
# 查询已有任务
python .\xhs_client.py task '任务ID'
# 采集作者；如需登录，由服务器操作员在Edge窗口扫码
python .\xhs_client.py collect '完整作者主页链接'
# 分页读取已采集作品，客户端会自动翻页汇总
python .\xhs_client.py collection '作品集ID'
```

文件先写入服务器选定目录：`作者名/作品标题/01.jpeg` 或视频文件；同名作品冲突会附加作品 ID。服务器同时生成 `作品说明.txt`，管理信息存于程序内部数据库，不生成混在作品中的 JSON。

示例客户端的 `download` 命令会继续通过带鉴权的文件接口，把媒体保存到调用者的 `--out` 目录，并校验文件大小。仅解析时的资源网址可能过期，需要时重新解析。

## 4. 接口清单

统一前缀 `/api/v1`；除文档与 OpenAPI 规范外，下列接口都需要 `Authorization: Bearer <API_KEY>`。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/health` | 检查解析后端和作者采集环境；未就绪返回503 |
| POST | `/tasks` | 创建单篇下载或解析任务，返回202与任务ID |
| GET | `/tasks` | 分页查询任务 |
| GET | `/tasks/{id}` | 查询状态、文件、资源地址、失败原因 |
| POST | `/tasks/{id}/cancel` | 停止任务，保留已保存文件 |
| POST | `/tasks/{id}/retry` | 生成重试任务，复用完整文件 |
| GET | `/tasks/{id}/files/{index}` | 带鉴权下载服务器文件；文件index从0开始 |
| POST | `/collections` | 输入作者主页，启动采集 |
| GET | `/collections` | 分页查询历史作品集 |
| GET | `/collections/{id}` | 查询作者采集状态、数量、完整性 |
| GET | `/collections/{id}/notes` | 分页查询笔记ID、标题与链接 |
| POST | `/collections/{id}/cancel` | 停止采集并保留已有结果 |
| POST | `/collections/{id}/download` | 下载已采集的全部或指定笔记，返回任务ID数组 |

分页参数 `offset=0&limit=50`，`limit` 为1–200。返回 `items,total,offset,limit`。

完整规范：`http://服务器IP:5557/api/v1/openapi.json`，也可导入随附的 `openapi.json`。导入工具后将服务器地址改为自己的实际地址。

浏览器跨域调用默认不开放 CORS；网页应用请通过自己的后端调用，并将密钥保留在后端。服务自带的同源 Swagger 文档可以直接测试。

## 5. 任务调用示例

下面代码可直接使用交付客户端的 `Client` 类。环境变量设置同上。

```python
import os
import uuid
from xhs_client import Client

client = Client(os.environ['XHS_BASE_URL'], os.environ['XHS_API_KEY'])
# 一个业务请求使用一个幂等键。网络重试时继续使用原键。
request_key = uuid.uuid4().hex
accepted = client.request('/tasks', {
    'url': '完整笔记分享链接',
    'mode': 'download',  # parse 表示只解析资源网址
    'index': [],        # 空数组表示全部；指定资源序号时从1开始
    'reuse': True
}, idempotency_key=request_key)

result = client.wait(accepted['id'])
if result['status'] == 'done':
    client.save_files(result, './我的下载')
else:
    print(result['status'], result['error'])
```

POST 统一发送 `Content-Type: application/json`。无额外参数的 POST（如取消）也要发送 `{}`。创建类接口推荐传 `Idempotency-Key`：1–128 位英文、数字、点、下划线、连字符。重复的相同请求返回原响应；同键不同内容返回409。已接受的幂等记录跨服务重启保存。管理员清除任务记录后，原键仍对应旧响应；新的业务操作应使用新键。

`202` 只代表服务接受任务，不代表作品已经下载成功。请按 `status_url` 或任务ID查询：

| 状态 | 含义 |
| --- | --- |
| queued / running / cancelling | 等待 / 处理中 / 正在停止，继续轮询 |
| done | 全部成功 |
| warning | 部分文件成功，检查error并重试 |
| failed | 失败，读取error.code与error.message |
| cancelled | 已停止 |

异步任务查询本身成功时返回HTTP200；任务失败体现在 `status=failed` 与 `error`。这与提交时因参数错误直接返回422不同。资源文件用返回的 `files[].download_url` 获取；下载也要携带 Bearer 密钥，不能把密钥拼到URL中。

## 6. 作者主页 → 采集 → 下载

```python
collection_id = client.request('/collections', {'url': '完整作者主页链接'})['id']
collection = client.wait(collection_id, kind='collections', timeout=900)
print(collection['status'], collection['note_count'], collection['complete'])

# 可分页读取完整列表并挑选作品
page = client.request(f'/collections/{collection_id}/notes?offset=0&limit=200')
selected_ids = [note['id'] for note in page['items'][:2]]
accepted = client.request(f'/collections/{collection_id}/download', {
    'note_ids': selected_ids
})
for task_id in accepted['ids']:
    result = client.wait(task_id)
    if result['status'] == 'done':
        client.save_files(result, './我的下载')

# 下载该作品集当前结果中的全部笔记（会真正创建所有下载任务）
# accepted = client.request(f'/collections/{collection_id}/download', {})
```

采集状态：`starting/scanning` 表示进行中；`login/attention` 需要服务器操作员扫码或处理验证；`complete` 表示已取得本站返回的分页结束信号；`partial/failed/cancelled` 都不保证完整。`complete=false` 时“下载全部”只指已经采集到的结果，不代表作者所有历史作品。已删除、私密或账号不可见的笔记无法保证获取。

服务器一次只运行一个作者采集任务；多个采集请求冲突返回409。下载队列活动任务上限1000，满时返回429；超大作品集可用 `note_ids` 分批提交，等待前一批完成后再提交下一批。新下载任务保存目录以提交时管理员设置为准，调用者不能远程指定任意服务器路径。

## 7. 常见错误

统一格式：`{"error":{"code":"INVALID_URL","message":"原因"},"request_id":"…"}`。

| HTTP | 典型原因 |
| --- | --- |
| 401 | API Key 未提供或错误 |
| 403 | 远程访问本机管理功能 |
| 404 | 任务、作品集或文件不存在 |
| 409 | 采集/下载正在运行，或幂等键冲突 |
| 413 / 415 | 请求过大 / Content-Type错误 |
| 422 | 链接、JSON、字段、图片序号或笔记ID错误 |
| 429 | 队列已满，请等待后再提交 |
| 503 | 解析服务或作者采集环境未就绪 |

任务自身的失败码包括 `NOTE_UNAVAILABLE`、`NO_RESOURCES`、`NETWORK_ERROR`、`UPSTREAM_ERROR` 和 `DOWNLOAD_INCOMPLETE`。同一密钥的调用者共享队列和任务记录，适用于可信协作者；目前没有独立租户、权限分级或每人额度。

旧的工作台代理 `/api/xhs/detail` 已停用并返回410，避免继续绕过新的保存规则。原始程序的5556端口不属于对外接口契约。

## 8. 另一台电脑独立安装服务器时

服务端需要 Windows、原始 XHS-Downloader 完整目录及 Python3.10+。作者采集额外需要安装 Node.js 与 Microsoft Edge，并在 `前端` 目录执行 `npm install --no-save playwright`。也可用 `XHS_NODE_EXECUTABLE` 指定node.exe绝对路径、`XHS_PLAYWRIGHT_MODULE` 指定playwright包目录。当前电脑兼容已有运行环境；新安装不要求使用Codex。

不要分发 `前端/browser-profile`、`前端/workbench.sqlite3`、`前端/archive.sqlite3`、`前端/legacy-tasks.json`、日志或 `_internal/Volume/settings.json` 中的个人登录配置。部署到新电脑应使用干净配置并重新登录。本次交付的是客户端、规范和说明，没有打包含登录资料的完整服务器。
